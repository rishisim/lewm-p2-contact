## Frozen conjunctive rule

A single fresh confirmation cohort was allowable only if **every** condition
was supported:

1. the formulation was more than new terminology for the current gate;
2. existing evidence suggested advantage over a nontrivial budget range;
3. one bounded cohort in an existing DGP could answer the question;
4. implementation could largely reuse accepted code without a new environment,
   refiner, gate architecture, or workflow layer; and
5. either result would change the central framing or a main figure/table.

Any failed or unresolved condition required stopping with the bounded paper.

## Why another cohort would be low paper value

A fresh PushT budget curve could make the empirical range confirmatory, but it
would not make the score a marginal-value-per-FLOP estimator, would not validate
the myopic rule for multistage Cube, and would not create a novel general
framework relative to adaptive inference and recent adaptive world-model work.
The manuscript already has the more important fresh evidence: two matched-
compute confirmations at locked operating points, plus honest negative and
boundary results. Spending a new cohort to elevate an exploratory curve would
change presentation more than scientific identity.

## Authorized use of this study

- Use the marginal-value formulation as a compact explanatory lens and a way to
  state the exact binary top-k conditions.
- Preserve the distinction between expectation budget, exact finite-cohort
  budget, and executable schedule.
- Optionally show the consumed-cohort frontier as explicitly exploratory,
  preferably outside the primary confirmation figure.
- Describe PushT binary as admitting a score-ranked top-k interpretation, not as
  an optimal compute-price policy.
- Describe Cube as a validated causal allocation heuristic whose multistage
  optimality is not established.
